# RavenBS-Fabric (Minecraft 1.20.1)

**RavenBS-Fabric** — это мощный и полнофункциональный клиент для Minecraft 1.20.1 на базе Fabric Loader. Это полный порт легендарного **Raven b+**, сохраняющий всю функциональность оригинала и добавляющий современные улучшения.

## ✨ Особенности

*   **Полная совместимость с 1.20.1**: Работает на новейших версиях Fabric.
*   **Огромный функционал**: Более 65 модулей для любых ситуаций (Legit, Blatant, Ghost).
*   **Локализация 🌍**: Полный перевод интерфейса на **Русский** и **Английский** языки.
*   **Производительность**: Оптимизирован для стабильной работы с высоким FPS.
*   **Настраиваемость**: Гибкая система профилей, конфигов и скриптов (в планах).

## 🚀 Установка

1. Скачайте и установите **[Fabric Loader](https://fabricmc.net/)** для версии 1.20.1.
2. (Рекомендуется) Установите **Fabric API**.
3. Поместите файл `ravenbs-fabric-x.x.x.jar` в папку `.minecraft/mods`.
4. Запустите игру.
5. Откройте меню клиента нажатием на **RSHIFT** (Правый Shift).

## 📦 Полный список модулей

Ниже приведен список всех доступных модулей, разделенных по категориям.

### ⚔️ Combat (Бой)
*Модули для преимущества в ПвП.*
*   **AimAssist**: Плавная помощь в наводке.
*   **AutoClicker**: Автокликер с эмуляцией джиттера.
*   **AutoWeapon**: Автоматический выбор лучшего оружия.
*   **BurstClicker**: Клик очередями (для BedWars/Sumo).
*   **ClickAssist**: Увеличение скорости клика / шанс двойного клика.
*   **HitBox**: Расширение хитбоксов сущностей.
*   **JumpReset**: Снижение откидывания прыжком.
*   **KillAura**: Автоматическая атака врагов (Blatant).
*   **Reach**: Увеличение дистанции удара.
*   **Reduce**: Уменьшение входящего откидывания (Legit).
*   **RodAimbot**: Автоматическое прицеливание удочкой.
*   **STap / WTap**: Автоматический стрейф/сброс спринта при ударе (Combo).
*   **TPAura**: Телепортация к врагам для атаки.
*   **Velocity**: Управление откидыванием (AntiKnockback).

### 🏃 Movement (Движение)
*Модули для перемещения.*
*   **AutoJump**: Автопрыжок.
*   **BHop (Speed)**: Распрыжка, увеличение скорости.
*   **Boost**: Временное ускорение.
*   **Fly**: Полет в режиме выживания.
*   **InvMove**: Возможность ходить с открытым инвентарем.
*   **KeepSprint**: Спринт не сбрасывается при ударе.
*   **LongJump**: Длинный прыжок.
*   **NoSlow**: Нет замедления при использовании предметов.
*   **SafeWalk**: Не дает упасть с края блока (как Shift).
*   **Sprint**: Автоматический спринт (OmniSprint).
*   **StopMotion**: Мгновенная остановка движения.
*   **Teleport**: Телепортация по нажатию (ClickTP).
*   **Timer**: Ускорение/замедление времени игры.
*   **VClip**: Вертикальная телепортация сквозь стены.

### 👤 Player (Игрок)
*Утилиты для игрока.*
*   **AntiFireball**: Отбивание фаерболов/снарядов.
*   **AntiVoid**: Спасение от падения в бездну.
*   **AutoPlace**: Автоклик ПКМ (FastBridge).
*   **AutoSwap**: Автосвап брони/предметов.
*   **AutoTool**: Автоматический выбор инструмента.
*   **Blink**: Эмуляция лагов (задержка пакетов).
*   **DelayRemover**: Удаление задержки 1.8 при ударах/ломании.
*   **FastMine**: Ускоренное ломание блоков.
*   **FastPlace**: Ускоренная установка блоков.
*   **Freecam**: Свободная камера (призрак).
*   **InvManager**: Автосортировка инвентаря.
*   **NoFall**: Нет урона от падения.
*   **NoRotate**: Блокировка вращения камеры сервером.
*   **Tower**: Автоматическая постройка столба вверх.
*   **WaterBucket**: Автоматический MLG Water Bucket.

### 👁️ Render (Визуал)
*Визуальные функции (ESP, HUD).*
*   **AntiShuffle**: Убирает эффект "тряски" текста.
*   **Arrows**: Стрелки указывающие на врагов.
*   **BedESP**: Подсветка кроватей сквозь стены.
*   **BreakProgress**: Отображение прогресса ломания блока.
*   **BridgeInfo**: Информация о текущей карте The Bridge.
*   **Chams**: Просвечивание моделей игроков сквозь стены.
*   **ChestESP**: Подсветка сундуков.
*   **ESP**: Подсветка коробок вокруг игроков.
*   **ExtendCamera**: Отдаление камеры в F5.
*   **FullBright**: Ночное зрение.
*   **HUD**: Интерфейс клиента (Info, Watermark).
*   **Indicators**: Индикаторы снарядов (стрелы, перлы).
*   **ItemESP**: Подсветка предметов на земле.
*   **MobESP**: Подсветка мобов.
*   **Nametags**: Улучшенные ники над головой.
*   **NoCameraClip**: Камера проходит сквозь блоки.
*   **NoHurtCam**: Отключение тряски камеры при получении урона.
*   **PlayerESP**: Продвинутая подсветка игроков.
*   **Potions**: Список активных зелий HUD.
*   **Radar**: Радар с игроками.
*   **Shaders**: Поддержка простых шейдеров.
*   **TargetHUD**: Инфо о текущей цели.
*   **Tracers**: Линии трейсеры к игрокам.
*   **Trajectories**: Траектория полета жемчуга/стрел.
*   **ViewPackets**: Дебаг пакетов.
*   **Xray**: Просвет руд.

### 🎮 Minigames (Мини-игры)
*Модули для конкретных режимов.*
*   **AutoRequeue**: Автозаход в следующую игру.
*   **AutoWho**: Инфо о противниках при заходе.
*   **BedAura**: Автоломание кровати (BedWars).
*   **BedWars**: Утилиты для BW (Resource display и др.).
*   **DuelsStats**: Статистика в дуэлях.
*   **MurderMystery**: Детектор убийцы.
*   **SkyWars**: Утилиты для SW.
*   **SpeedBuilders**: Помощник для Speed Builders.
*   **SumoFence**: Заборы для сумо (AntiFall).

### 🌍 World (Мир)
*   **AntiBot**: Игнорирование ботов/NPC.
*   **FastBreak**: (World) Быстрое разрушение.
*   **Scaffold**: Автостроитель мостов.
*   **Weather**: Изменение времени/погоды клиентом.

### ⚙️ Other (Другое)
*   **AntiAFK**: Анти-АФК.
*   **Anticheat**: Детектор читеров (ALERT).
*   **ChatBypass**: Обход фильтров чата.
*   **FakeChat**: Фейковые сообщения.
*   **FakeLag**: Имитация лагов.
*   **LatencyAlerts**: Оповещение о лагах сети.
*   **NameHider**: Скрытие ников (Streamer Mode).

### 🎉 Fun (Веселье)
*   **Derp**: Хаотичное вращение головой.
*   **Spin**: Вращение персонажа.

## 💻 Команды чата

| Команда | Описание | Пример |
| :--- | :--- | :--- |
| `.bind <модуль> <клавиша>` | Назначить клавишу для модуля. | `.bind KillAura R` |
| `.toggle <модуль>` | Включить/Выключить модуль. | `.toggle HUD` |
| `.friend add/remove <ник>` | Добавить или удалить друга (KillAura игнорирует). | `.friend add Ibragim` |
| `.friend list` | Показать список друзей. | `.friend list` |
| `.config save/load <имя>` | Сохранить или загрузить профиль настроек. | `.config save legit` |
| `.config list` | Показать доступные профили. | `.config list` |
| `.updatecheck on/off/status` | Вкл/выкл/проверить авто-проверку обновлений. | `.updatecheck status` |
| `.help` | Показать список всех команд. | `.help` |

Проверку обновлений можно отключить или включить в любой момент командой `.updatecheck off/on`.

## ⚠️ Отказ от ответственности
Использование данного модификации на лицензионных серверах (Hypixel, Mineland и др.) может привести к блокировке аккаунта. Используйте функции категории **Client** и **Render** безопасно, но **Blatant** модули (KillAura, Fly, Speed) используйте на свой страх и риск.
